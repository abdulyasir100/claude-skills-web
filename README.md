# claude-skills

A curated collection of [Agent Skills](https://code.claude.com/docs/en/skills) for Claude Code —
engineering, design, research, writing, and workflow skills that are general enough to be useful
in any project.

Each skill is a folder containing a `SKILL.md` with YAML frontmatter (`name`, `description`) and
whatever reference files, scripts, or examples it needs. Claude loads a skill automatically when
its description matches what you're doing.

## Install

Clone into your personal skills directory:

```bash
git clone https://github.com/abdulyasir100/claude-skills-web.git ~/claude-skills
```

Then copy the ones you want into `~/.claude/skills/` (user-wide) or `.claude/skills/` (per project):

```bash
cp -r ~/claude-skills/python-patterns ~/.claude/skills/
```

Restart Claude Code and run `/skills` to confirm it loaded.

## Catalog

`index.json` is the machine-readable catalog. Regenerate it (and the table below) after adding or
editing a skill:

```bash
python build_index.py
```
